# 测试环境目录说明

## 目录作用

存放根级 Vitest 测试环境初始化代码，供核心库、共享 UI 和各端测试复用。

## 文件列表

| 文件 | 作用 |
| ---- | ---- |
| `setup.ts` | 初始化 fake-indexeddb、Web Crypto、btoa、atob 等测试环境 API |

## 技术说明

- 测试框架使用 Vitest，配置文件在根目录 `vitest.config.ts`
- DOM 环境使用 `happy-dom`
- IndexedDB 使用 `fake-indexeddb/auto` 模拟
- Web Crypto 使用 Node `webcrypto` 补齐

## 使用示例

```bash
pnpm test
pnpm test:coverage
pnpm test -- packages/core/src/crypto.test.ts
```

## 扩展方式

- 新增全局测试 polyfill 时放在 `setup.ts`
- 新增测试 helper 时优先按功能拆分到本目录独立文件，再由测试按需导入

## 注意事项

- 不在这里 mock 业务模块，业务 mock 应放在对应测试文件中
- 不在这里写测试用例，只做测试环境初始化
