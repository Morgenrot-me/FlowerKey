# 核心库源码目录说明

更新时间：2026-07-28
更新概要：收紧身份包装格式校验，增加旧数据状态识别与持久化白名单。

## 目录作用

花钥核心逻辑库，包含加密算法、数据层、同步引擎，供所有端（插件、桌面、移动）复用。

## 文件列表

| 文件 | 作用 |
| ---- | ---- |
| `index.ts` | 统一导出入口，对外暴露所有公共 API |
| `models.ts` | 数据模型定义（Entry、ChangeLog、MasterData 等接口） |
| `crypto.ts` | 加密模块：PBKDF2 密钥派生、HMAC-SHA256 密码生成、AES-256-GCM 加解密、记忆密码验证 |
| `db.ts` | IndexedDB 数据层（基于 Dexie.js）：Entry CRUD、ChangeLog 自动记录、主密码数据管理，并统一按最近使用时间排序密码条目 |
| `direct-password.ts` | 锁定态首屏直算共享流程：统一正式模式校验、独立计算模式、临时条目沉淀与最近使用时间更新 |
| `crypto.test.ts` | FK-DP1 固定向量、输入规范化、字符类型与长度约束测试 |
| `direct-password.spec.ts` | 无状态身份密语输入与代号规范化匹配测试 |

## 技术说明

- 加密全部使用 Web Crypto API，零 WASM 依赖，跨平台兼容
- 密钥分离：masterKey / verifyHash / dbKey / identityWrapKey 使用不同盐域派生
- 身份密语以版本化 AES-256-GCM envelope 存储，解锁后只存在于内存
- 主密码数据读取区分 `missing` / `current` / `unsupported`，旧格式不得覆盖为新初始化
- 主密码数据写入前按白名单重建对象，并拒绝携带 `userSalt` / `identitySecret` 明文字段的混合格式
- 首次初始化使用事务型 `createMasterData()`，只允许从 `missing` 创建；恢复码更新使用独立 `setMasterData()`，陈旧页面不能覆盖生成根
- 恢复码只恢复原主密码，主密码和身份密语不提供普通修改路径
- PBKDF2 迭代次数 ≥ 600,000 次（符合 NIST 2023 建议）
- FK-DP1 区分代号执行 NFC、首尾空白移除和 ASCII 小写化
- FK-DP1 仅支持 `alphanumeric` / `with_symbols` 与 8/16/32 位
- 稳定版发布后，任何影响固定测试向量的改动都视为协议破坏
- IndexedDB 按 `type`、`folder`、`updatedAt` 建索引
- `db.ts` 提供 `touchLastUsed()`，用于桌面端、插件端记录密码最近使用时间
- `updateEntry()` 支持通过 `undefined` 显式清空加密字段，密码生成/存储模式切换依赖该行为清理互斥字段

## 注意事项

- 所有加密操作为异步，返回 Promise
- 不直接依赖浏览器扩展 API，可在 Node.js / Tauri 环境复用
- 发现发布前或损坏的主密码数据时，客户端必须停止初始化并提示用户明确清除开发数据
