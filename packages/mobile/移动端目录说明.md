# 移动端目录说明

> 更新时间：2026-07-28
> 更新概要：Android 自动填充接入身份密语包装信封解密，并增加 Web Crypto 跨端固定向量。

## 目录作用

FlowerKey 的 Android/iOS 移动端应用，基于 Capacitor 7 封装 Vue 3 前端，并在 Android 端提供系统自动填充服务。

## 文件列表

| 文件 / 目录 | 作用 |
|-------------|------|
| `src/` | 移动端 Vue 应用源码、页面、状态管理与 SQLite 适配层 |
| `android/` | Capacitor Android 原生工程，包含 AutofillService 与原生插件 |
| `android/app/src/main/java/com/flowerkey/app/PasswordGenerator.java` | FK-DP1 Android 原生共享生成器 |
| `android/app/src/main/java/com/flowerkey/app/IdentityEnvelopeCrypto.java` | 与 core 一致的身份密语 AES-256-GCM 包装信封解密器 |
| `capacitor.config.ts` | Capacitor 应用配置 |
| `vite.config.ts` | Vite 构建配置 |
| `index.html` | 前端入口 HTML |
| `package.json` | 移动端包配置、脚本与依赖 |
| `tailwind.config.js` | Tailwind CSS 扫描范围与主题配置 |
| `postcss.config.js` | PostCSS 配置 |

## 技术说明

- 前端使用 Vue 3、TypeScript、Pinia 与 Tailwind CSS。
- 本地数据使用 `@capacitor-community/sqlite`，数据库名为 `flowerkey`。
- Android 原生层通过 `flowerkeySQLite.db` 读取同一 SQLite 数据库，用于 AutofillService 匹配与填充。
- 敏感字段使用 core 统一的 AES-256-GCM 格式加密，WebDAV 配置等 secret config 也使用数据库密钥加密。
- Android AutofillService 依赖 `FlowerKeyApp` 内存中的 `dbKey` 与 `masterKey`，不持久化主密码或密钥。
- 未解锁时，Android 认证弹窗用输入的主密码解开本地 `identityEnvelope`，不再从配置读取身份密语明文。
- SQLite 首次初始化在 `BEGIN IMMEDIATE` 事务中执行 create-if-missing，避免并发页面覆盖已经建立的生成根。
- AutofillService 与认证弹窗共同调用 `PasswordGenerator`，不得各自复制生成算法。
- 原生固定向量可脱离 Gradle 使用 `PasswordGeneratorVectorCheck`、`IdentityEnvelopeVectorCheck` 与 `javac/java` 验证。
- Android Gradle 构建使用 Java 21，当前通过 `android/gradle.properties` 指向 Android Studio JBR：`D:\APP\C\Android\jbr`。

## 使用示例

```bash
pnpm --filter @flowerkey/mobile build
cd packages/mobile && npx cap sync android
powershell -Command "Set-Location 'packages/mobile/android'; .\gradlew.bat --no-daemon --max-workers=1 \"-Dorg.gradle.jvmargs=-Xms64m -Xmx1024m -XX:CICompilerCount=2 -XX:ReservedCodeCacheSize=64m -XX:+HeapDumpOnOutOfMemoryError\" \"-Dorg.gradle.parallel=false\" :app:assembleRelease"
```

## 扩展方式

- 新增页面：在 `src/pages/` 新增 Vue 页面，并在布局或路由入口接入。
- 新增状态：在 `src/stores/` 新增 Pinia store，优先复用 core 类型和工具函数。
- 新增原生能力：在 `android/app/src/main/java/com/flowerkey/app/` 添加 Capacitor Plugin，并在 `MainActivity` 注册。
- 新增数据库字段：先更新 `src/db-sqlite.ts` schema 和迁移，再同步 Android 原生 SQL 读取逻辑。

## 注意事项

- 移动端不要直接使用 core 的 Dexie `db`，必须通过 `src/db-sqlite.ts` 访问 SQLite。
- 会影响同步的写操作必须记录 changelog，避免多端数据不一致。
- 修改加密字段时，需要同时确认 Vue 层、SQLite 层、Android Autofill 原生层的字段处理一致。
- 移动端表单控件应统一使用 `.input` 组件样式，保持浅色/深色模式下的品牌外观一致。
- Android APK 构建需使用 PowerShell 执行 Gradle，bash 下 `gradlew` 不稳定。
