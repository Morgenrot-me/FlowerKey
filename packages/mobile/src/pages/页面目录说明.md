# 页面目录说明

> 更新时间：2026-07-29
> 更新概要：移除书签与普通笔记页面，新增 FK-SECRET-1 加密秘密库。

## 目录作用

移动端页面目录，承载首次引导、解锁、主布局以及密码、秘密库和设置等核心界面。

## 文件列表

| 文件 | 作用 |
| ---- | ---- |
| `AutofillPromptPage.vue` | 首次设置后提示 Android 用户开启系统自动填充，并可直接跳转系统设置。 |
| `ForceResetPage.vue` | 发布前旧强制重置页的空壳，占位保留但未注册路由且不包含凭据修改逻辑。 |
| `MainLayout.vue` | 主布局：根据屏幕宽度切换底部标签栏或侧边栏，承载四个主 Tab。 |
| `SecretTab.vue` | 秘密库：管理账号凭据、Token、密钥、恢复码和任意秘密，列表不展示秘密内容。 |
| `OnboardingPage.vue` | 首次欢迎页：介绍花钥核心理念并引导进入设置流程。 |
| `PasswordTab.vue` | 密码页：支持搜索、标签过滤、生成/存储模式、新建编辑、复制密码与最近使用排序。 |
| `SettingsTab.vue` | 设置页：管理同步、自动填充、身份密语提示、恢复原主密码和导入导出，并说明不可变生成根。 |
| `SetupPage.vue` | 首次设置页：设置并二次确认记忆密码与必填身份密语。 |
| `UnlockPage.vue` | 锁定态首屏：默认提供正式密码直算，保留登入数据库与恢复码入口；身份密语提示不在锁定态显示，记忆密码提示仅由用户主动点击查看。 |

## 技术说明

- 以 `Pinia` 为状态中枢，主要依赖 `useMainStore`、`useEntriesStore`、`useSyncStore`。
- 通过 `Capacitor` 插件接入 Android 自动填充能力，并在设置页检查开启状态。
- 页面复用 `ui/src` 中的 `ConfirmDialog`、`Toast`、`PasswordStrength`、`AppIcon` 等共享组件。
- `MainLayout.vue` 处理移动端安全区、平板布局和 Tab 切换，是所有主功能页的容器。
- `SettingsTab.vue` 同时覆盖 WebDAV / iCloud、恢复原主密码和加密备份导入导出，并展示可验证的最近一次成功同步时间，是移动端安全与同步中心。
- 根组件识别 `unsupported` 主密码数据并停止初始化，避免覆盖旧配置后孤立已有加密条目。
- `SettingsTab.vue` 通过静态引入 `db-sqlite` 读取恢复码状态，避免构建期出现同模块动静态混用 warning。

## 使用示例

```ts
// 首次使用常见流程
OnboardingPage -> SetupPage -> UnlockPage -> MainLayout
```

```ts
// Android 用户首次设置后可继续进入
SetupPage -> AutofillPromptPage -> 系统自动填充设置
```

## 扩展方式

1. 新增页面时，在本目录添加 `.vue` 文件，并在 `MainLayout.vue` 中注册入口。
2. 若新增主功能 Tab，需要同步补上图标、激活态样式和布局切换逻辑。
3. 若扩展密码或条目字段，需同时修改 store、数据层和对应页面表单/列表展示。
4. 若新增平台能力，优先通过 Capacitor 插件做适配，再在页面中接入。

## 注意事项

- `PasswordTab.vue` 同时支持生成模式与存储模式，修改时需同时验证两条交互路径。
- `PasswordTab.vue` 的确定性配置仅允许两种字符模式与 8/16/32 位。
- `SettingsTab.vue` 中恢复码和备份属于安全关键流程；不得重新加入普通主密码或身份密语修改入口。
- `SecretTab.vue` 列表不得显示秘密内容摘要，所有可识别字段必须留在整体加密载荷中。
- 自动填充和 iCloud 仅在特定平台可用，新增逻辑时不要假设所有设备都支持。
- 首次设置与引导页的文案需要保持克制、易懂，并延续现有蓝色提示卡与圆角视觉风格。
