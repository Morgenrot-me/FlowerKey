# 桌面端目录说明

## 目录作用

FlowerKey 的 Windows 桌面端应用，基于 Tauri 2 封装 Vue 3 前端，复用 core 的 IndexedDB 数据层、加密逻辑与 WebDAV 同步引擎。

## 文件列表

| 文件 / 目录 | 作用 |
|-------------|------|
| `src/` | 桌面端 Vue 应用源码、页面与状态管理 |
| `src-tauri/` | Tauri 2 原生工程、窗口配置、打包配置与 Rust 入口 |
| `index.html` | 前端入口 HTML |
| `vite.config.ts` | Vite 构建配置 |
| `package.json` | 桌面端包配置、脚本与依赖 |
| `tailwind.config.js` | Tailwind CSS 扫描范围与主题配置 |
| `postcss.config.js` | PostCSS 配置 |
| `app-icon.png` | 桌面端应用图标源文件 |

## 技术说明

- 前端使用 Vue 3、TypeScript、Pinia 与 Tailwind CSS。
- 桌面壳使用 Tauri 2，配置位于 `src-tauri/tauri.conf.json`。
- 数据层复用 `@flowerkey/core` 的 Dexie/IndexedDB 实现。
- WebDAV 同步请求由前端发起，Tauri CSP 需允许用户配置的 HTTPS WebDAV 地址。
- 版本号需要与根 `package.json`、Tauri 配置和 Cargo 包版本保持一致。

## 使用示例

```bash
pnpm --filter @flowerkey/desktop build
pnpm --filter @flowerkey/desktop tauri build
```

## 扩展方式

- 新增页面：在 `src/pages/` 新增 Vue 页面，并在 `MainLayout.vue` 接入。
- 新增状态：在 `src/stores/` 新增 Pinia store，优先复用 core 类型和数据层方法。
- 新增 Tauri 能力：在 `src-tauri/src/` 添加 Rust command，并同步更新 Tauri 权限/配置。
- 新增打包产物：调整 `src-tauri/tauri.conf.json` 的 bundle 配置，并同步产物收集脚本。

## 注意事项

- 修改 `src-tauri/tauri.conf.json` 会影响桌面端安全策略和打包行为，需同步验证桌面构建。
- 桌面端不要引入移动端 SQLite 适配层，数据访问应走 core `db`。
- 桌面锁定页内容需限制合理宽度，避免输入框在宽窗口下横向铺满。
- 修改版本号后运行 `pnpm version:sync`，保持根包、子包和 Tauri 配置一致。
- WebDAV 连接依赖 CSP `connect-src`，收紧 CSP 前必须确认同步功能仍可访问 HTTPS 地址。
