# 页面目录说明

## 目录作用

桌面端页面目录，承载首次引导、解锁、主布局以及密码/书签/笔记/设置等主要界面。

## 文件列表

| 文件 | 作用 |
| ---- | ---- |
| `BookmarkTab.vue` | 书签页：展示书签列表，支持搜索、新建、删除与编辑。 |
| `MainLayout.vue` | 主布局：左侧导航切换密码、书签、笔记、设置四个主页面。 |
| `NoteTab.vue` | 笔记页：展示私密笔记列表，支持搜索、新建与编辑。 |
| `OnboardingPage.vue` | 首次欢迎页：说明花钥的核心理念并引导进入设置流程。 |
| `PasswordTab.vue` | 密码页：支持搜索、标签过滤、生成/存储模式、新建编辑、复制密码与最近使用排序。 |
| `SettingsTab.vue` | 设置页：管理 WebDAV、恢复码、书签加密、改主密码、导入导出，并展示行动型提示、导入摘要与最近一次成功同步时间。 |
| `SetupPage.vue` | 首次设置页：设置记忆密码与可选个人标识，并加入极简示例帮助理解使用方式。 |
| `UnlockPage.vue` | 解锁页：输入记忆密码或恢复码解锁本地数据。 |

## 技术说明

- 桌面端使用 Vue 3 + Pinia，数据能力与 mobile 共用同一套 core 模型。
- 页面复用 `ui/src` 中的 `ConfirmDialog`、`Toast`、`PasswordStrength`、`AppIcon` 等共享组件。
- 密码复制主要依赖浏览器环境能力，不需要 Capacitor 插件。
- `MainLayout.vue` 提供桌面侧栏式导航，保持多页面切换的一致结构。
- `SettingsTab.vue` 是桌面端同步与安全的集中入口，围绕 WebDAV、恢复码和改主密码展开，并展示可验证的最近一次成功同步时间。

## 使用示例

```ts
// 桌面端首次使用常见流程
OnboardingPage -> SetupPage -> UnlockPage -> MainLayout
```

```ts
// 日常使用
PasswordTab / BookmarkTab / NoteTab / SettingsTab
```

## 扩展方式

1. 新增页面时，在本目录添加 `.vue` 文件，并在 `MainLayout.vue` 中注册导航入口。
2. 若扩展条目字段，需同步修改 store、数据层与页面表单/列表展示。
3. 若新增共享交互，优先复用 `ui/src` 公共组件，避免与 mobile 端产生视觉分叉。
4. 若引入桌面端专属能力，优先基于标准 Web API 实现，减少平台耦合。

## 注意事项

- `SettingsTab.vue` 中恢复码、书签加密、改主密码均属于高风险操作，必须保留清晰的后果提示。
- 桌面端仅支持 WebDAV，同步逻辑不要混入移动端专属的 iCloud 或自动填充判断。
- `PasswordTab.vue` 的生成与存储模式都要保持可用，改动时需同时验证复制路径与最近使用排序。
- 首次设置与欢迎页需保持与 mobile 端一致的理解成本，同时遵守当前项目的轻量视觉风格。
