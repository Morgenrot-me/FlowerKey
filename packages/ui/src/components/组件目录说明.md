# UI 组件目录说明

更新时间：2026-05-17
更新概要：补充密码编辑表单在生成/存储模式切换时需清理互斥字段的说明。

## 目录作用

Vue 3 共享 UI 组件，供插件侧边栏、桌面端、移动端复用，统一输入样式、反馈组件与关键业务表单。

## 文件列表

| 文件 | 作用 |
| ---- | ---- |
| `UnlockForm.vue` | 锁定态首屏表单：默认提供正式密码直算，支持校验失败后切换独立模式，并保留登入数据库与恢复码入口。 |
| `SetupForm.vue` | 首次设置表单：设置记忆密码与可选个人标识，展示密码强度和极简示例。 |
| `OnboardingForm.vue` | 引导表单：插件端紧凑版欢迎页，介绍花钥的核心理念。 |
| `EntryList.vue` | 条目列表：展示密码/书签/文件引用，密码条目突出长度、字符集与最近使用时间，并轻微强化 `临时` 标签。 |
| `EntryForm.vue` | 条目编辑表单：新建/编辑 Entry，支持密码、书签、文件引用三种类型；密码生成/存储模式切换时显式提交互斥字段清理。 |
| `SettingsPage.vue` | 设置页：管理 WebDAV、锁定策略、书签加密、恢复码、改主密码、导入导出，并加入行动型提示、导入摘要与最近一次成功同步时间。 |
| `PasswordStrength.vue` | 密码强度指示条：实时评估密码强度并给出视觉反馈。 |
| `ConfirmDialog.vue` | 确认对话框：替代原生 `confirm()`，支持危险操作样式和深色模式。 |
| `Toast.vue` | Toast 提示：轻量级操作反馈，自动消失。 |

## 技术说明

- 基于 Vue 3 `<script setup>` 编写，供 extension、desktop、mobile 三端复用。
- `SetupForm.vue` 复用 `PasswordStrength.vue` 和 `AppIcon.vue`，保持首次设置体验一致。
- `SettingsPage.vue` 通过 `useConfirm()` 管理恢复码重建、清空数据等确认流程。
- 设置页中的行动型提示采用浅蓝/浅橙卡片样式，与现有圆角和文字层级保持一致。
- 导入结果摘要统一展示“读取总数 / 新增数 / 跳过数”，便于快速确认是否真的导入成功。
- 同步区域同时展示本次同步结果与持久化的最近一次成功同步时间，避免应用重启后失去验证依据。
- `EntryForm.vue` 保存密码条目时，生成模式会清空 `storedPassword`，存储模式会清空 `charsetMode` / `passwordLength`，避免旧模式字段残留影响复制和自动填充。

## 扩展方式

1. 新增通用表单或反馈组件时，优先放在本目录，避免三端重复实现。
2. 若扩展 `SettingsPage.vue` 的设置项，优先复用已有输入样式、提示卡片和 `ConfirmDialog`。
3. 若新增危险操作，统一接入 `useConfirm()`，不要直接使用原生 `confirm()`。
4. 若新增操作反馈，优先使用 `Toast.vue` 或现有摘要文本，不额外引入新的反馈体系。

## 注意事项

- 三端共享组件修改后，需要同步检查 desktop、mobile、extension 的调用是否仍然匹配。
- `SetupForm.vue` 中的记忆密码、确认密码、个人标识校验顺序不要随意改动，以免影响首次设置成功率。
- `SettingsPage.vue` 中涉及恢复码、书签加密、改主密码的文案均为安全关键提示，调整时需保持明确且克制。
- 行动型提示应延续现有 UI 风格，不引入突兀的新配色、新组件范式或重型引导布局。
