# 公共静态资源目录说明

## 目录作用

本目录保存浏览器插件构建可用的公共静态资源，包括备用 manifest 与插件图标资源。

## 文件列表

| 文件 / 目录 | 作用 |
|-------------|------|
| `manifest.json` | 浏览器插件 manifest 备用文件，版本号由 `pnpm version:sync` 同步维护。当前 Vite 构建实际复制上级目录的 `manifest.json`。 |
| `icons/` | 浏览器插件图标资源目录，用于扩展商店、工具栏和系统展示。 |

## 技术说明

- 当前插件构建配置在 `vite.config.ts` 的 `closeBundle()` 中复制 `packages/extension/manifest.json` 到 `dist/manifest.json`。
- 本目录的 `manifest.json` 保持同步，避免手动加载或未来构建配置调整时出现旧版本号。
- 图标资源应保持 Manifest V3 所需尺寸，至少覆盖 16、48、128 像素。

## 使用示例

```bash
pnpm version:sync
pnpm --filter @flowerkey/extension build
```

## 扩展方式

1. 新增静态资源时放入本目录或其子目录，并在构建配置中确认是否会被复制到 `dist/`。
2. 新增 manifest 字段时，同时检查上级目录 `manifest.json` 和本目录备用 manifest。
3. 图标变更后应重新构建插件并检查 `dist/icons/` 输出。

## 注意事项

- 不要只修改本目录 manifest，正式构建入口仍以上级目录 manifest 为准。
- 版本号应通过 `pnpm version:sync` 统一同步，避免多端版本不一致。
- 静态资源命名应保持清晰稳定，避免浏览器缓存和 manifest 引用失效。
