# 侧边栏目录说明

> 更新时间：2026-07-28
> 更新概要：旧或损坏的主密码数据进入阻断提示，不再允许覆盖初始化。

## 目录作用

Chrome 侧边栏（Side Panel）完整管理界面，点击工具栏图标打开。

## 文件列表

| 文件 | 作用 |
| ---- | ---- |
| `index.html` | 侧边栏入口 HTML |
| `main.ts` | Vue 应用挂载入口 |
| `App.vue` | 侧边栏根组件，加载完整管理视图；锁定态展示首屏直算，发现旧或损坏数据时停止初始化 |

## 技术说明

- 工具栏点击行为由扩展入口控制，侧边栏本身通过 runtime 连接维持当前内存解锁态
- 与 content script 通过 `chrome.runtime.sendMessage` 通信
- `chrome.storage.session` 只保存非秘密状态；主密码与身份密语通过后台内存状态恢复，不持久化
- 密码条目生成后自动复制，并按最近使用时间刷新排序
