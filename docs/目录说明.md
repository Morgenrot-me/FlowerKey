# 花钥文档目录说明

> 更新时间：2026-07-28
> 更新概要：建立产品安全与实现计划文档目录。

## 目录作用

`docs/` 保存需要在代码实现前确定的架构、安全边界和实施计划。确定性密码协议的永久兼容规范仍保存在仓库根目录 `密码生成协议.md`。

## 文件列表

- `plans/`：经过确认、可直接指导实现与验收的设计方案。

## 扩展方式

新增跨端架构、安全模型或数据格式前，先在 `plans/` 写清输入、存储格式、数据流、失败行为和测试门禁，再修改代码。

## 注意事项

- 文档不得包含真实主密码、身份密语、恢复码、Token 或 WebDAV 凭据。
- 会改变 FK-DP1 输出的设计不得在此直接覆盖旧协议，必须新增协议版本。
